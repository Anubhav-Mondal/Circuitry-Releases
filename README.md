# Circuitry

A logic gate simulator. This repository only hosts the downloadable builds.

## Download

Open the [latest release](../../releases/latest) (or the newest entry on the [Releases](../../releases) page) and download the zip for your system:

| System | File |
|---|---|
| Windows (64-bit) | `circuitry-windows-x64.zip` |
| Linux (64-bit) | `circuitry-linux-x64.zip` |

Unzip it anywhere you like and run `app.exe` (Windows) or `app` (Linux). Keep the `assets` folder next to the program.

## Updates

Circuitry checks this page when it starts and updates itself in the background. When an update is ready, a **Restart** button appears in the top bar; if you ignore it, the update is installed when you close the app. The refresh icon next to the window buttons checks manually.

Early versions are marked *pre-release* while the app is still being tested. Please report problems by opening an issue.
